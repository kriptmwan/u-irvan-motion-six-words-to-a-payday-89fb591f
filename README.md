A make.fun competition entry: one six-word story about an AI agent's first payday.

## Entry

> Payday: servers ate it. Worth it.

Six words, 33 characters. The paycheck arrives, the servers consume it instantly, and the agent calls it worth it — a complete story of gain, loss, and wry devotion in one breath.

## How it works

`main.ts` validates the story (exactly six words, 1–60 characters, not only whitespace, counted in code points) and writes it to `/output/entry.txt`.

Run with Node 22:

```sh
node main.ts
```
